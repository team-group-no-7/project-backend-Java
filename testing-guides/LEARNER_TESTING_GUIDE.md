# 🎓 LearnHub Learner Module Testing Guide

> This guide explains how to test the Learner Workspace APIs built by Riya in `learner-dashboard-new`.
> For full details, see [src/main/java/com/learnhub/backend/user/LEARNER_MODULE_TESTING.md](src/main/java/com/learnhub/backend/user/LEARNER_MODULE_TESTING.md).

## ⚡ Quick Testing Summary

- **Profile API**: `GET /api/learners/profile/{userId}` & `PUT /api/learners/profile/{userId}`
- **Dashboard API**: `GET /api/learners/dashboard/{userId}`
- **Library API**: `GET /api/purchases/library/{userId}`
- **Sessions API**: `GET /api/sessions/{userId}`
